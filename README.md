# BITS ML Assignment 2 — Classification Model Explorer

## a. Problem statement
This project implements and compares multiple classification algorithms on one public dataset and exposes the models through an interactive Streamlit web application. The application allows a test CSV to be uploaded, lets the user select a model, and displays the required evaluation metrics and confusion matrix/classification report.

## b. Dataset description
**Dataset:** Breast Cancer Wisconsin (Diagnostic), available through scikit-learn and originally sourced from UCI.

- Problem type: Binary classification
- Instances: 569
- Input features: 30 numeric features
- Target classes: 0 = malignant, 1 = benign
- Train/test split: 80/20 using `random_state=42` and stratification

The dataset satisfies the assignment requirement of at least 500 instances and at least 12 features.

## Performance observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best overall balance on the held-out test set, with the highest accuracy, F1 and MCC and a very high AUC. Standardization helps the linear classifier handle features with different scales. |
| Decision Tree | Easy to interpret, but its test performance is lower than the other models. A single tree can be more sensitive to the particular training split and can overfit. |
| kNN | Strong recall and F1 after feature standardization. Its prediction cost grows with the training data because neighbours must be searched at inference time. |
| Naive Bayes | Very high AUC and recall with a simple probabilistic model. Its conditional-independence assumption limits performance when features are strongly correlated. |
| Random Forest | Strong and stable ensemble performance with high AUC, recall and F1. It reduces the variance of a single decision tree by averaging many trees. |
| Overall Winner | **Logistic Regression** for this particular split because it has the strongest overall Accuracy, F1 and MCC while maintaining excellent AUC. |

## Repository structure

```text
project-folder/
├── app.py
├── requirements.txt
├── README.md
├── test_data.csv
├── model_metrics.csv
├── feature_names.json
└── model/
    ├── __init__.py
    ├── train_models.py
    ├── logistic_regression.py
    ├── decision_tree.py
    ├── knn.py
    ├── naive_bayes.py
    └── random_forest.py
```

No `.joblib` files are required. Each model is defined as actual Python source code in the `model/` directory, and the Streamlit application trains the selected model from those definitions using a cached resource.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

To regenerate the held-out test data and comparison metrics:

```bash
python model/train_models.py
```
